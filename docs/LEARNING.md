- [ ] What does `package-lock.json` do?
- [ ] How does Vite differ from Create React App?

### Phase 2: Authentication
- [ ] Why HTTP-only cookies over localStorage for JWT?
- [ ] Explain the bcrypt cost factor.
- [ ] What is the middleware chain in Express?

### Phase 3-4: API & Data Modelling
- [ ] When to embed vs reference in MongoDB?
- [ ] How does TanStack Query invalidate cache?
- [ ] What is the snapshot pattern and why use it?

### Phase 5: Workout Logging
- [ ] How do you persist state across page refreshes?
- [ ] Explain optimistic updates and rollback.

### Phase 6: Analytics
- [ ] Walk through a MongoDB aggregation for weekly volume.
- [ ] How do you calculate estimated 1RM?

### Phase 7: Algorithms
- [ ] Explain double progression in your own words.
- [ ] How does your plateau detection avoid false positives?
- [ ] What is a DAG and how does it apply to skill trees?

### Phase 8: Production
- [ ] What does a multi-stage Dockerfile buy you?
- [ ] How do you handle secrets in CI/CD?
